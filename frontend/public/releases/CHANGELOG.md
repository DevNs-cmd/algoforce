# TallyGPT Desktop Engine — Release Notes

## Version 1.0.0 (Latest Release - July 31, 2026)

### Highlights & Key Improvements
- **Native Windows Desktop Installer**: Fully compiled, zero-dependency Windows `.exe` setup package (`TallyGPT_Setup.exe`).
- **Tally Prime & ERP 9 Auto-Discovery**: Automatic HTTP proxy detection connecting to Tally instances running on `localhost:9000` or custom ports.
- **Air-Gapped Vector Index Engine**: 100% on-premises vector index creation for sub-second ledger search without external data telemetry.
- **Automated Reconciliation Workflows**: GST 2B tax rate mismatch detection and automated bank statement cross-checking.
- **Executive Board Pack Generator**: One-click generation of board-ready P&L, Balance Sheet, and Working Capital analytics.
- **Enterprise Security Hardening**: AES-256 local encrypted indexing and granular role-based access control (RBAC).

### Compatibility
- **Windows**: Windows 10 & 11 (64-bit)
- **Tally Supported**: Tally Prime (v1.0 to v4.x), Tally ERP 9 (Release 5.0+)
- **System Memory**: 4 GB RAM minimum (8 GB recommended)
